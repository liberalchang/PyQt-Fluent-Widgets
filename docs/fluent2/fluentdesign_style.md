# Windows 11 Fluent Design 设计准则

**版本**: 1.0
**日期**: 2025-12-29
**来源**: 微软官方文档 (Windows apps design)

## 1. 简介
本准则旨在为开发者提供基于微软 Windows 11 Fluent Design 系统的核心设计指导。Windows 11 的设计语言强调“人类化、通用性”，通过柔和的几何形状、更加平静的色调以及模拟物理材质的视觉效果（如 Mica 和 Acrylic），创造出直观、专注且跨平台一致的用户体验。本准则严格依据微软官方文档制定，确保应用程序在视觉和交互上与 Windows 11 生态系统无缝融合。

## 2. 设计准则主体

### 2.1 核心设计原则 (Design Principles)

**FD-01: 保持直观与高效 (Effortless)**
*   **规范描述**: 应用程序应设计得更快、更直观。通过清晰的布局和交互逻辑，使用户能够轻松、专注且精确地完成任务。
*   **适用场景**: 所有用户交互流程设计，特别是核心任务路径。

**FD-02: 营造平静与专注 (Calm)**
*   **规范描述**: 界面应柔和且整洁，利用淡入背景的效果。体验应感觉温暖、空灵且平易近人，帮助用户保持冷静和专注，避免不必要的视觉干扰。
*   **适用场景**: 整体视觉风格、背景处理、空白区域（Padding/Margin）的使用。

**FD-03: 适应性与个性化 (Personal)**
*   **规范描述**: 应用程序应无缝适应用户的设备操作习惯、个人需求和偏好，允许用户展现自我。
*   **适用场景**: 响应式布局、输入法适配（触控/鼠标/笔）、主题设置。

**FD-04: 熟悉且新颖 (Familiar)**
*   **规范描述**: 在外观上保持新颖的同时，操作逻辑应保持熟悉。用户无需重新学习即可上手使用，平衡创新与习惯。
*   **适用场景**: 导航结构、标准控件的使用、常用快捷键。

**FD-05: 跨平台一致性 (Complete)**
*   **规范描述**: 提供跨平台的视觉无缝体验，确保用户在不同设备和平台上工作时，仍能获得一致的 Windows 体验。
*   **适用场景**: 多端应用开发、Web 与 Native 混合应用。

### 2.2 视觉与组件规范 (Signature Experiences)

**FD-06: 材质系统 (Materials)**
*   **规范描述**: 使用 **Mica (云母)** 和 **Acrylic (亚克力)** 等材质来模拟真实世界的物理质感。材质用于建立 UI 与环境的连接，区分应用程序的层级。
    *   **Mica**: 用于应用背景，建立层级基础。
    *   **Acrylic**: 用于瞬态表面（如菜单、弹窗），提供背景模糊效果。
*   **适用场景**: 窗口背景、侧边栏、弹出菜单、对话框。

**FD-07: 几何图形 (Geometry)**
*   **规范描述**: 采用 **圆角 (Rounded Corners)** 几何设计。更新后的几何图形更加柔和，旨在创建更易访问、更具吸引力的体验。
*   **适用场景**: 窗口边角、按钮、卡片、输入框等所有 UI 容器。

**FD-08: 提升与分层 (Elevation & Layering)**
*   **规范描述**: 利用阴影和光照（提升）将一个表面与另一个表面重叠，在同一视图中创建视觉区分区域。这是应用层次结构的基础。
*   **适用场景**: 浮动操作按钮、对话框、下拉菜单、卡片式布局。

**FD-09: 色彩系统 (Color)**
*   **规范描述**: 利用颜色建立视觉层次结构并传达含义。基调应平和，仅在必要时使用强调色突出重要项。必须支持 **浅色 (Light)** 和 **深色 (Dark)** 模式。
*   **适用场景**: 主题切换、状态指示（错误/成功）、交互反馈。

**FD-10: 字体排版 (Typography)**
*   **规范描述**: 使用 **Segoe UI Variable** 字体。通过字重和大小创建结构和层次，最大限度提高易读性。版式的主要任务是传达信息。
*   **适用场景**: 标题、正文、标签、数字显示。

**FD-11: 意象与图标 (Iconography)**
*   **规范描述**: 使用 **Segoe Fluent Icons** 系统字体。图标设计应采用更柔和的几何图形和现代隐喻，帮助用户快速理解并导航。
*   **适用场景**: 导航栏图标、命令栏按钮、状态指示器。

**FD-12: 动态效果 (Motion)**
*   **规范描述**: 动效必须是直接反应且符合上下文的。它应为用户输入提供即时反馈，并强化空间范例（如页面跳转的方向性）。
*   **适用场景**: 页面切换、元素点击反馈、加载状态、显示/隐藏过渡。

### 2.3 交互与布局 (Interaction & Layout)

**FD-13: 导航结构 (Navigation)**
*   **规范描述**: 使用可预测的结构化导航模式（如 NavigationView）。帮助用户了解应用结构并轻松浏览。
*   **适用场景**: 侧边导航栏、顶部标签页、面包屑导航。

**FD-14: 命令与操作 (Commanding)**
*   **规范描述**: 以清晰、一致的方式呈现动作（如 CommandBar）。确保用户了解他们可以执行的操作。
*   **适用场景**: 工具栏、上下文菜单、操作按钮布局。

**FD-15: 布局网格 (Layout)**
*   **规范描述**: 使用网格、间距和对齐模式来组织内容。确保布局平衡且具有可预测性，提高清晰度和流程。
*   **适用场景**: 列表视图、仪表盘、表单设计。

## 3. 总结
Windows 11 Fluent Design 是一套不断进化的设计语言，其核心在于通过光感、深度、动效、材质和比例来创造直观、和谐且吸引人的用户体验。开发者在实施过程中，应始终贯彻“平静”、“直观”和“个性化”的原则，充分利用系统提供的材质（Mica/Acrylic）和控件库，确保应用既具有独特的品牌个性，又与 Windows 生态系统保持高度一致。

### 附录 A：关键术语解释

*   **Fluent Design**: 微软推出的设计语言，强调光、深度、动效、材质和比例。
*   **Mica (云母)**: 一种不透明的动态材质，将用户的主题和桌面壁纸融入应用背景，用于长期存在的 UI 表面。
*   **Acrylic (亚克力)**: 一种半透明材质，通过模糊背景内容建立层次感，常用于瞬态 UI（如菜单）。
*   **Elevation (提升)**: Z 轴深度的概念，通常通过阴影来表现元素之间的层级关系。
*   **Segoe UI Variable**: Windows 11 的新系统字体，针对不同尺寸的易读性进行了优化。
