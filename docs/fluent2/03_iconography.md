# Windows 11 Fluent Design: 图标与排版 (Iconography & Typography)

**最后更新**: 2025-12-29
**参考**: [Iconography](https://learn.microsoft.com/zh-cn/windows/apps/design/signature-experiences/iconography)

## 1. 图标系统 (Iconography)

### 1.1 Segoe Fluent Icons
Windows 11 使用 **Segoe Fluent Icons** 字体。其特点是：
*   **几何化**: 基于简单的几何形状。
*   **圆角**: 线条端点和转角通常为圆形，与 UI 圆角呼应。
*   **单色**: 默认使用文本颜色，支持适应主题。

### 1.2 线性与填充 (Line vs. Filled)
*   **线性图标 (Outline)**: 默认状态。线条宽度通常为 1px 或 1.5px (在 16px 网格中)。
*   **填充图标 (Filled)**: 选中/激活状态。用于明确指示当前活动项（如底部导航栏的选中 Tab）。

### 1.3 尺寸规范
*   **标准尺寸**: 16x16px (用于菜单、按钮内部)。
*   **大尺寸**: 24x24px (用于命令栏、导航项)。
*   **其它**: 20px, 32px 可根据需要使用，但应保持网格对齐。

### 1.4 应用图标 (App Icons)
*   应用图标应具有独特的轮廓和品牌识别度。
*   支持不同尺寸的缩放 (Scale 100%, 200%, 400%)。
*   在任务栏、开始菜单和设置中显示。

## 2. 字体排版 (Typography)

### 2.1 Segoe UI Variable
Windows 11 引入了 **Segoe UI Variable** 字体，它是可变字体 (Variable Font)。
*   **优势**: 针对不同字号进行了光学优化。
    *   **Small**: 适用于正文和标签，提高小字号下的易读性。
    *   **Display**: 适用于大标题，笔画更加精致优雅。

### 2.2 类型阶梯 (Type Ramp)
推荐使用标准的字号层级：
*   **Caption**: 12px (Regular) - 辅助说明
*   **Body**: 14px (Regular) - 正文
*   **Body Strong**: 14px (Semibold) - 正文强调
*   **Subtitle**: 20px (Semibold) - 分组标题
*   **Title**: 28px (Semibold) - 页面标题
*   **Display**: 68px (Semibold) - 巨型展示

### 2.3 对齐
*   大多数文本建议 **左对齐** (LTR 语言)。
*   数字数据在表格中建议 **右对齐**。
