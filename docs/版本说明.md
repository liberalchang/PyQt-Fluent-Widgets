基于对项目配置文件的分析，我来详细解释包的安装参数设置和两种安装方式的区别：

## 包安装参数设置

项目使用 [setup.py](cci:7://file:///d:/BaiduSyncdisk/mydir/CustomPackages/pyside6-fluent-widgets/setup.py:0:0-0:0) 进行包配置，关键参数如下：

### 基础依赖 (`install_requires`)
```python
install_requires=[
    "PySide6>=6.4.2",
    "PySideSix-Frameless-Window>=0.7.6", 
    "darkdetect",
]
```

### 可选依赖 (`extras_require`)
```python
extras_require = {
    'full': ['scipy', 'pillow', 'colorthief']
}
```

## 两种安装方式区别

### 1. 基础版本安装
```shell
pip install PySide6-Fluent-Widgets -i https://pypi.org/simple/
```

**安装内容：**
- 仅安装 `install_requires` 中的基础依赖
- 包含：PySide6、PySideSix-Frameless-Window、darkdetect
- **不包含**：scipy、pillow、colorthief

### 2. 完整版本安装
```shell
pip install "PySide6-Fluent-Widgets[full]" -i https://pypi.org/simple/
```

**安装内容：**
- 基础依赖 + 可选依赖
- 包含所有基础包：PySide6、PySideSix-Frameless-Window、darkdetect
- **额外包含**：scipy、pillow、colorthief

## 功能差异

### 基础版本功能
- 核心UI组件和基础功能
- 主题检测和切换
- 无边框窗口支持

### 完整版本额外功能
- **scipy**：科学计算支持，可能用于图像处理和数学运算
- **pillow**：图像处理库，支持 `AcrylicLabel` 等图像相关组件
- **colorthief**：颜色提取工具，用于主题色彩分析

## 总结

主要区别在于 `AcrylicLabel` 组件的可用性：
- 基础版本：无法使用 `AcrylicLabel`
- 完整版本：支持 `AcrylicLabel` 和其他图像处理相关功能

这种设计允许用户根据需求选择安装体积，避免不必要的依赖包。
