# PyQt-Fluent-Widgets 窗口详细布局说明
基于 PyQt-Fluent-Widgets 组件库及 Fluent Design 风格，该窗口采用「**左侧导航栏 + 顶部标题栏 + 右侧堆叠功能区**」的经典架构，各区域分层明确、职责清晰，以下是完整布局拆解：


## 一、整体架构总览
窗口核心分为三大模块：**标题栏（顶部）、左侧导航栏、右侧功能区**，整体为无边框设计（依赖 `PySideSix-Frameless-Window` 实现），支持亮暗主题切换、窗口缩放/全屏等基础操作，各模块通过信号槽实现联动（如导航点击切换功能页）。


## 二、各区域详细布局
### 1. 顶部标题栏（TitleBar）
标题栏为自定义无边框样式，适配 Windows/macOS/Linux 跨平台风格，核心功能是窗口控制与身份标识，结构如下：
| 区域位置 | 组件/元素 | 核心功能 | 适配细节 |
|----------|-----------|----------|----------|
| 左侧（Windows）/ 中间（macOS） | 应用图标 + 应用名称 | 展示应用身份，点击图标可弹出应用菜单（如关于、退出） | Windows 图标居左，macOS 图标居中；支持拖拽图标移动窗口 |
| 右侧 | 窗口控制按钮组 | 包含「最小化、最大化/还原、关闭」三个按钮 | - Windows：按钮hover时显示背景色，关闭按钮hover为红色<br>- macOS：按钮为圆形图标，仅hover时显示图标<br>- Linux：风格贴近系统原生窗口 |
| 额外扩展区（可选） | 搜索框 / 自定义按钮 | 快速功能入口（如全局搜索、主题切换按钮） | 可通过 `CustomTitleBar` 类自定义添加，示例见 `examples/navigation/navigation_bar/demo.py` |

**关键特性**：支持拖拽移动窗口（标题栏空白区域）、双击标题栏最大化/还原、按 ESC 退出全屏模式。


### 2. 左侧导航栏（NavigationInterface）
左侧导航栏是功能入口核心，按布局分为 **TopLayout（顶部固定区）、ScrollLayout（中间滚动区）、BottomLayout（底部固定区）** 三部分，支持展开/折叠模式切换（默认展开宽度 ~240px，折叠后仅显示图标）。

#### （1）TopLayout（顶部固定区）
位于导航栏最上方，放置高频固定功能，不随滚动变化：
- **返回按钮（ReturnButton）**：触发导航历史回退，搭配 `QStackedWidget` 实现功能页回溯（如从「设置页」退回「首页」）；
- **菜单按钮（MenuButton）**：控制导航栏展开/折叠，点击后切换导航栏显示模式（展开显示文字+图标，折叠仅显示图标）；
- **顶层功能按钮（可选）**：如「首页」「搜索」等全局核心功能，优先级高于中间滚动区功能。

#### （2）ScrollLayout（中间滚动区）
导航栏核心功能区，用于放置大量功能入口（如多模块导航、树形菜单），支持滚动查看，核心组件为 `NavigationPushButton`（导航按钮）：
- **组件构成**：每个导航按钮包含「Fluent 风格图标 + 功能文字」，支持选中态、hover态样式变化（选中时左侧显示主题色高亮条，hover时背景色变浅）；
- **功能支持**：
  - 单选互斥：点击一个按钮自动取消其他按钮选中状态（通过 `QButtonGroup` 管理）；
  - 多级菜单：支持嵌套子菜单（如「音乐库」下包含「本地音乐」「在线音乐」），点击父按钮展开/折叠子菜单；
  - 滚动适配：当按钮数量超过导航栏高度时，自动显示垂直滚动条，不挤压其他区域。

#### （3）BottomLayout（底部固定区）
位于导航栏最下方，放置全局设置或用户相关功能，不随滚动变化：
- **用户信息组件**：如 `NavigationAvatarWidget`（头像 + 用户名），点击可弹出用户菜单（个人中心、退出登录）；
- **系统功能按钮**：如「设置」「帮助」「关于」，对应 `FluentIcon.SETTING`「FluentIcon.HELP」等图标，点击跳转至对应功能页；
- **主题切换按钮（可选）**：快速切换亮暗主题，图标随主题自动切换（亮色显示「月亮」，暗色显示「太阳」）。

**导航栏关键特性**：支持亚克力模糊效果（通过 `setAcrylicEnabled(True)` 开启）、导航历史记录（返回按钮回溯）、展开宽度自定义（默认 240px，可通过 `setExpandWidth()` 调整）。


### 3. 右侧功能区（StackedContentArea）
右侧是功能展示核心，采用 `QStackedWidget`（堆叠窗口）作为容器，**一次仅显示一个功能页**，其他页面隐藏在「栈内」，结构如下：
| 层级 | 组件/容器 | 核心功能 | 联动逻辑 |
|------|-----------|----------|----------|
| 容器层 | QStackedWidget | 承载所有功能页（如首页、设置页、数据表格页），管理页面切换 | 接收左侧导航栏的点击信号，通过 `setCurrentWidget()` 切换显示的功能页，保留每个页面的状态（如滚动位置、输入内容） |
| 页面层 | 自定义功能页（QWidget 子类） | 具体业务功能实现（如数据展示、表单输入、媒体播放） | 每个功能页需继承 `QWidget`，通过 `addWidget()` 加入堆叠容器，示例见 `examples/gallery/app/view/home_interface.py` |
| 辅助层 | 加载动画 / 空页面提示 | 页面切换时的过渡动画、无数据时的提示占位 | 可通过 `EntranceTransitionStackedWidget` 实现页面切换动画（如淡入淡出、滑动） |

**常见功能页布局**：
- 首页：采用 `FlowLayout` 流式布局，展示功能卡片（如「基础输入示例」「日期选择示例」）；
- 设置页：采用 `SettingCardGroup` 分组布局，包含开关卡片（如「云母效果开启」）、下拉卡片（如「主题选择」）、按钮卡片（如「选择文件夹」）；
- 数据页：采用 `QTableWidget`/`ListView` 布局，展示列表/表格数据，搭配顶部筛选栏（如搜索框、排序按钮）。


## 三、跨区域联动逻辑
各区域并非独立，通过 Qt 信号槽实现联动，核心交互场景如下：
1. **导航栏 ↔ 功能区**：点击左侧导航按钮（如「设置」），导航栏发送 `currentItemChanged` 信号，功能区 `QStackedWidget` 接收信号并切换到对应功能页；
2. **标题栏 ↔ 导航栏**：双击标题栏最大化窗口时，导航栏自动适配窗口宽度（展开模式下宽度不变，折叠模式下跟随窗口缩放）；
3. **主题切换联动**：标题栏/导航栏/功能区共用 `qconfig` 全局配置，切换主题（亮/暗/Auto）时，所有组件样式（如背景色、文字色、边框色）自动同步更新（依赖 `StyleSheetBase` 类实现样式适配）。


## 四、布局核心依赖与示例
1. **核心组件**：
   - 导航栏：`NavigationInterface`（主容器）、`NavigationPushButton`（导航按钮）；
   - 标题栏：`StandardTitleBar`（基础款）、`CustomTitleBar`（自定义款）；
   - 功能区：`QStackedWidget`（堆叠容器）、`FluentWindow`（窗口主类）。
2. **参考示例**：
   - 完整布局示例：`examples/gallery/demo.py`（综合演示所有区域）；
   - 导航栏示例：`examples/navigation/navigation2/demo.py`（三部分布局清晰）；
   - 自定义标题栏示例：`examples/navigation/navigation_bar/demo.py`（含搜索框扩展）。
