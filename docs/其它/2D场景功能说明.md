# 2D场景功能说明

## 官方默认操作

基于 Vispy PanZoomCamera，2D场景支持以下官方默认操作：

### 🖱️ 鼠标交互
- **左键拖动**: 平移视图（pan）
- **右键拖动或滚轮**: 缩放视图（zoom）

### 📋 可用功能
- 添加/删除图形元素（折线、散点、矩形、椭圆、文本等）
- 自动调整视图范围
- 主题切换（亮色/暗色）
- 可见性控制（显示/隐藏图形元素）
- 网格显示

### ❌ 不支持的功能
- **旋转**: PanZoomCamera 不支持旋转操作
- **翻转**: 已移除自定义翻转功能

### 🔧 技术实现
- 使用 Vispy PanZoomCamera
- 支持 STTransform（缩放和平移）
- 不支持 MatrixTransform 旋转

### 📝 使用说明
1. 左键拖动平移视图
2. 右键拖动或滚轮缩放视图
3. 使用控制面板添加图形元素
4. 使用复选框控制元素可见性
5. 点击"重置视图"恢复初始视图

## 代码结构
- `VispyCanvas2D`: 2D画布实现
- `VispyWidget2D`: 2D控件封装
- 只保留官方默认操作，无自定义扩展
