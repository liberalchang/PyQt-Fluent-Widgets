ToolTip 工具提示模块
====================

ToolTip 模块提供工具提示控件，用于显示控件的简要说明。支持多种位置和自定义样式。

主要功能
--------

- **提示显示** - 显示控件的简要说明
- **多种位置** - 支持多种提示位置配置
- **自定义样式** - 支持自定义提示样式
- **延迟显示** - 支持显示延迟设置
- **位置管理** - 智能的位置计算和调整

核心组件
--------

ToolTip
~~~~~~~~

工具提示控件，提供基础的提示显示功能。

ToolTipPositionManager
~~~~~~~~~~~~~~~~~~~~

工具提示位置管理器，处理位置计算逻辑。

使用示例
--------

基础工具提示使用：

.. code-block:: python

   from qfluentwidgets.components.widgets.tool_tip import ToolTip
   
   # 创建工具提示
   tooltip = ToolTip("这是工具提示")
   
   # 为控件设置工具提示
   widget.setToolTip(tooltip)

注意事项
--------

1. **内容简洁** - 保持工具提示简洁明了
2. **位置选择** - 选择合适的提示位置
3. **显示延迟** - 合理设置显示延迟时间
