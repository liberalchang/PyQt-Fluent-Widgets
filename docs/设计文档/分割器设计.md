你这张图是一个**自定义风格分割器（Splitter Handle）**，特点是：

* 一个可拖动的矩形区域
* 中间有一条短横条作为视觉指示
* Hover 时背景灰度增加
* Press（左键按住）时灰度进一步提高
* 支持水平 / 垂直两种方向

下面给你一份完整的 **PySide6 自定义分割器设计说明文档（架构级说明）**，用于实现一个可复用组件。

---

# 一、组件设计目标

实现一个：

> CustomSplitter（自定义 QSplitter）

特性：

1. 支持 Horizontal / Vertical
2. 自定义 Handle UI
3. 支持 Hover / Press 状态
4. 支持样式渐变
5. 可复用、可扩展

---

# 二、整体架构设计

```
QSplitter
   └── CustomSplitter
           └── CustomSplitterHandle (继承 QSplitterHandle)
```

---

# 三、类结构设计

## 1️⃣ CustomSplitter

继承：

```python
class CustomSplitter(QSplitter)
```

职责：

* 重写 createHandle()
* 返回自定义 Handle

---

## 2️⃣ CustomSplitterHandle

继承：

```python
class CustomSplitterHandle(QSplitterHandle)
```

职责：

* 自定义绘制
* 管理 hover / press 状态
* 控制方向布局
* 响应鼠标事件

---

# 四、视觉设计规范

## 1️⃣ 布局结构

以水平分割为例：

```
┌───────────────┐
│               │
│     content   │
│               │
├─────┬─────────┤  ← handle
│     │         │
│     │  bar    │
│     │         │
└─────┴─────────┘
```

Handle 视觉结构：

```
[   背景矩形   ]
        ───
        横条
```

---

## 2️⃣ 尺寸规范

| 属性       | 推荐值  |
| -------- | ---- |
| Handle宽度 | 12px |
| 中间横条宽度   | 24px |
| 横条高度     | 3px  |
| 圆角       | 4px  |

---

## 3️⃣ 颜色规范

| 状态     | 背景颜色             |
| ------ | ---------------- |
| Normal | rgba(0,0,0,0.05) |
| Hover  | rgba(0,0,0,0.12) |
| Press  | rgba(0,0,0,0.20) |

横条颜色：

```
rgba(120,120,120,0.8)
```

---

# 五、状态机设计

需要维护内部状态：

```python
self._hovered: bool
self._pressed: bool
```

状态变化规则：

| 事件                | 状态变化            |
| ----------------- | --------------- |
| enterEvent        | hovered = True  |
| leaveEvent        | hovered = False |
| mousePressEvent   | pressed = True  |
| mouseReleaseEvent | pressed = False |

---

# 六、绘制逻辑设计（核心）

重写：

```python
def paintEvent(self, event):
```

绘制流程：

1. 创建 QPainter
2. 开启抗锯齿
3. 根据状态选择背景色
4. 绘制圆角矩形
5. 计算中间 bar 位置
6. 绘制横条

---

## 状态颜色选择逻辑

```python
if self._pressed:
    bg_color = press_color
elif self._hovered:
    bg_color = hover_color
else:
    bg_color = normal_color
```

---

# 七、方向适配设计（关键）

Handle 必须支持：

* Qt.Horizontal
* Qt.Vertical

判断方式：

```python
self.orientation()
```

---

## 1️⃣ Horizontal Splitter

表示左右分割：

* handle 是竖条
* bar 是横线

```
│
│   ───
│
```

---

## 2️⃣ Vertical Splitter

表示上下分割：

* handle 是横条
* bar 是竖线

```
──────
   │
   │
```

---

## 绘制差异处理

### Horizontal

```python
rect = self.rect()
bar_width = 24
bar_height = 3
bar_rect = QRect(
    (rect.width() - bar_width)//2,
    (rect.height() - bar_height)//2,
    bar_width,
    bar_height
)
```

### Vertical

```python
bar_rect = QRect(
    (rect.width() - 3)//2,
    (rect.height() - 24)//2,
    3,
    24
)
```
