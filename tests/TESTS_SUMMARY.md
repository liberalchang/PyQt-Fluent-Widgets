# Tests 文件简要说明

本文档用于管理 tests 目录中每个测试文件的简要说明，便于快速定位组件与功能示例。

- test_vispy_widget.py：Vispy 2D/3D 综合演示，包含相机、交互与窗口效果
- test_drawing_view.py：绘图视图基础功能示例
- drawing_app.py：交互式绘图应用示例
- draw_icon_example.py：图标绘制示例

## 图表
- echarts_test.py：ECharts 图表动态更新示例
- chart_presets_test.py 图表view快速接口

- table_view.py：表格视图与委托样式示例

- test_top_navigation_simple.py：简化版顶部导航示例
- test_top_navigation_window.py：完整顶部导航窗口示例
- test_navigation_layout_fix.py：导航布局修复验证
- test_navigation_titlebar_fix.py：导航标题栏修复验证
- test_maximize_fix.py：窗口最大化修复验证
- test_simple_maximize.py：简化最大化窗口示例
- test_maximize_mica_effect.py：最大化云母特效验证
