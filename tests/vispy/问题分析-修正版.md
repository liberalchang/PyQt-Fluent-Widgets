# Vispy 测试程序问题分析与解答（修正版）

## 问题 1：为什么 test_navigation.py 在点击最大化后云母效果会失效？

### 问题重新理解

**澄清**：
- `test_vispy_widget.py`（未修改前）：云母特效**正常工作**，包括最大化后
- `test_navigation.py`：云母特效在最大化后**失效**

### 根本原因分析

#### 1. **Windows 系统行为**
- Windows 在窗口状态改变（最大化、还原、全屏）时会**清除视觉特效**
- 云母特效（Mica Effect）依赖于 Windows DWM Composition API
- 需要在窗口状态改变后**重新应用**云母特效

#### 2. **FluentWidget 基类的问题**

在 `qfluentwidgets/window/fluent_window.py` 中的 `FluentWidget` 类：

```python
class FluentWidget(BackgroundAnimationWidget, FramelessWindow):
    def __init__(self, parent=None):
        super().__init__(parent=parent)
        # 在初始化时会根据配置启用云母特效
        self.setWindowEffect(qconfig.get(qconfig.windowEffect))
    
    def showEvent(self, e):
        super().showEvent(e)
        # 窗口显示时重新应用特效 ✓
        if self.isMicaEffectEnabled():
            self.windowEffect.setMicaEffect(self.winId(), isDarkTheme())
    
    # 缺少 changeEvent 处理 ✗
    # 导致最大化/还原时不会重新应用特效
```

**关键问题**：`FluentWidget` 基类**没有实现 `changeEvent`** 来处理窗口状态变化。

#### 3. **为什么 test_vispy_widget.py 正常？**

因为 `test_vispy_widget.py` 中有 `resizeEvent` 的延迟刷新：

```python
class VispyTestWindow(FluentWindow):
    def resizeEvent(self, e):
        super().resizeEvent(e)
        # 延迟重新应用云母特效
        if hasattr(self, '_isMicaEnabled') and self._isMicaEnabled:
            QTimer.singleShot(10, lambda: self.setMicaEffectEnabled(True))
```

**但这不是最佳方案**：
- `resizeEvent` 在任何窗口大小改变时都会触发（包括用户拖动窗口边缘）
- 频繁调用 `setMicaEffectEnabled` 可能导致性能问题
- **正确的做法是监听窗口状态变化（`changeEvent`）**

---

### 正确的解决方案

#### 方案 1：在子类中重写 changeEvent（推荐）

修改 `test_navigation.py`：

```python
class Window(FluentWindow):
    def changeEvent(self, event):
        """重写 changeEvent 来处理窗口状态变化"""
        from PySide6.QtCore import QEvent, QTimer
        super().changeEvent(event)
        
        if event.type() == QEvent.WindowStateChange:
            # 窗口状态改变后重新应用云母/亚克力特效
            if self.isMicaEffectEnabled():
                # 延迟 10ms 重新应用，确保窗口状态完全改变
                QTimer.singleShot(10, lambda: self.setMicaEffectEnabled(True))
            elif self.isAcrylicEffectEnabled():
                QTimer.singleShot(10, lambda: self.setAcrylicEffectEnabled(True))
```

**原理**：
- `QEvent.WindowStateChange` 会在窗口最大化、还原、最小化、全屏时触发
- 延迟 10ms 是为了确保 Windows DWM 已经完成窗口状态切换
- 只在云母/亚克力特效启用时重新应用，避免不必要的调用

#### 方案 2：修改 FluentWidget 基类（根本解决，需要修改 qfluentwidgets 库）

在 `qfluentwidgets/window/fluent_window.py` 中添加：

```python
class FluentWidget(BackgroundAnimationWidget, FramelessWindow):
    # ... 现有代码 ...
    
    def changeEvent(self, e):
        """处理窗口状态变化"""
        super().changeEvent(e)
        
        if e.type() == QEvent.WindowStateChange:
            # 窗口状态改变后重新应用特效
            QTimer.singleShot(10, self._reapplyWindowEffect)
    
    def _reapplyWindowEffect(self):
        """重新应用窗口特效"""
        if self.isMicaEffectEnabled():
            self.setMicaEffectEnabled(True)
        elif self.isAcrylicEffectEnabled():
            self.setAcrylicEffectEnabled(True)
```

## 问题 2：测试代码中可见性控制组的作用是什么？

### 功能说明

**可见性控制组（Visibility Control Group）** 是测试程序中的一个重要功能模块，用于动态控制场景中各个图形元素的显示/隐藏。

### 实现细节

```python
# 1. 在控制面板中创建可见性控制组
vis_group = QGroupBox("可见性")
self.vis_layout = QVBoxLayout(vis_group)

# 2. 为每个图形元素添加复选框
self._add_visibility_checkbox('sine', '正弦曲线', True)
self._add_visibility_checkbox('cosine', '余弦曲线', True)
self._add_visibility_checkbox('markers', '散点', True)

# 3. 复选框状态改变时调用
def _on_visibility_changed(self, visual_id: str, state: int):
    if self.has_vispy and visual_id in self.visual_ids:
        is_visible = (state == 2)  # Qt.Checked = 2
        self.vispyWidget.set_visible(self.visual_ids[visual_id], is_visible)
```

### 使用场景

1. **调试与开发**
   - 快速切换元素可见性，排查渲染问题
   - 对比不同元素的显示效果

2. **用户交互**
   - 允许用户自定义显示内容
   - 类似图层管理器（如 Photoshop 的图层面板）

3. **性能优化**
   - 隐藏不需要的元素，减少渲染负担
   - 在大数据量场景中特别有用

### 底层实现

调用 `VispyWidget.set_visible(visual_id, visible)` 会：

1. 在 `vispy_canvas.py` 中找到对应的 `VisualEntry`
2. 调用 `entry.set_visible(visible)`
3. 底层调用 Vispy 的 `visual.visible = visible`
4. Vispy 自动跳过不可见元素的渲染

### 优势

- ✅ **实时响应**：复选框改变立即生效，无需刷新
- ✅ **内存高效**：隐藏的元素不渲染，但数据保留在内存中
- ✅ **可扩展**：可以轻松添加更多控制选项（透明度、颜色等）

## 问题 3：在测试代码中 2D 场景，Vispy 如何旋转画布（XY 平面）？

### 重新理解问题

**澄清**：
- 用户问的不是 **Z 轴旋转**（那确实不支持）
- 而是 **XY 平面如何旋转**（即翻转 X/Y 轴，模拟旋转 180 度效果）

### 解决方案：XY 平面翻转（Flip）

#### 实现原理

PanZoomCamera 虽然不支持任意角度旋转，但支持 **轴翻转（Flip）**：

```python
# Vispy 相机的 flip 属性
camera.flip = (flip_x, flip_y, flip_z)
# flip_x: True=左右镜像（绕 Y 轴旋转 180°）
# flip_y: True=上下镜像（绕 X 轴旋转 180°）
# flip_z: True=前后镜像（绕 Z 轴旋转 180°，2D 场景无效）
```

#### 已实现的 API

**VispyCanvas2D 中添加的方法**：

```python
class VispyCanvas2D(VispyCanvasBase):
    def flip_x(self, enable: bool = None) -> bool:
        """翻转 X 轴（左右镜像）
        
        Args:
            enable: True=启用翻转, False=禁用翻转, None=切换当前状态
            
        Returns:
            当前翻转状态
        """
        if enable is None:
            self._flip_x = not self._flip_x
        else:
            self._flip_x = enable
        
        self.view.camera.flip = (self._flip_x, self._flip_y, False)
        return self._flip_x
    
    def flip_y(self, enable: bool = None) -> bool:
        """翻转 Y 轴（上下镜像）"""
        # 类似实现
    
    def reset_flip(self):
        """重置所有翻转状态"""
        self._flip_x = False
        self._flip_y = False
        self.view.camera.flip = (False, False, False)
```

**VispyWidget2D 中的接口**：

```python
widget2d = VispyWidget2D()

# 翻转 X 轴（左右镜像）
widget2d.flip_x()          # 切换状态
widget2d.flip_x(True)      # 启用翻转
widget2d.flip_x(False)     # 禁用翻转

# 翻转 Y 轴（上下镜像）
widget2d.flip_y()

# 重置所有翻转
widget2d.reset_flip()
```

---

### XY 平面翻转的效果

| 操作 | 效果 | 等效于 |
|------|------|--------|
| `flip_x(True)` | 左右镜像 | 绕 Y 轴旋转 180° |
| `flip_y(True)` | 上下镜像 | 绕 X 轴旋转 180° |
| `flip_x(True) + flip_y(True)` | 既左右又上下翻转 | 绕 Z 轴旋转 180° |

**示例**：

```python
# 原始图形：正弦曲线从左到右递增
widget2d.add_line(pos, color='red')

# 左右翻转后：正弦曲线从右到左递增
widget2d.flip_x(True)

# 上下翻转后：正弦曲线倒置
widget2d.flip_y(True)

# 同时翻转：相当于旋转 180°
widget2d.flip_x(True)
widget2d.flip_y(True)
```

flip_group = QGroupBox("XY 平面翻转")

**回调函数**：
```python
def _on_flip_x_clicked(self):
    """翻转 X 轴（左右镜像）"""
    if self.has_vispy:
        is_flipped = self.vispyWidget.flip_x()
        self.flipXBtn.setChecked(is_flipped)

def _on_flip_y_clicked(self):
    """翻转 Y 轴（上下镜像）"""
    if self.has_vispy:
        is_flipped = self.vispyWidget.flip_y()
        self.flipYBtn.setChecked(is_flipped)

def _on_reset_flip_clicked(self):
    """重置所有翻转"""
    if self.has_vispy:
        self.vispyWidget.reset_flip()
        self.flipXBtn.setChecked(False)
        self.flipYBtn.setChecked(False)
```

### 为什么不支持任意角度旋转？

**技术限制**：
- PanZoomCamera 设计为 2D 查看器，只有 (x, y, zoom) 参数
- 没有旋转角度参数
- 这是 Vispy 库的设计决策，确保 2D 场景的简单性和性能

**替代方案**：
1. **使用翻转**（已实现）：适合 90°/180° 的旋转需求
2. **使用 3D 场景**：如需任意角度旋转，使用 `VispyWidget3D`，然后固定视角为顶视图
3. **变换数据**：在添加图形前对数据进行旋转变换（不推荐，会导致用户交互混乱）

## 总结

- **问题**：`test_navigation.py` 最大化后云母特效失效

### 问题 2 答案
可见性控制组的作用：

2. 类似图层管理器，提供精细的可见性控制

  - `flip_y(True)`：上下镜像（绕 X 轴 180°）
  - 同时翻转：等效于绕 Z 轴旋转 180°
