## 核心前提：Vispy 场景体系的基础概念
Vispy 的「场景（Scene）」基于**场景图（Scene Graph）** 构建，核心组件包括：
- `SceneCanvas`：场景画布（承载所有绘图元素）；
- `ViewBox`：视图容器（管理相机、视口、交互）；
- `Visual`：可视化元素（2D/3D 绘图的核心载体）；
- `Camera`：相机（控制 2D/3D 视角交互）。

所有 2D/3D 绘图均围绕「Canvas + View + Visual + Camera」的组合实现，差异仅在于 Visual 类型和 Camera 类型的选择。

## 一、Vispy 2D 绘图场景（官方 API 核心内容）
### 1. 2D 场景核心组件（API 路径）
| 组件类型       | 官方 API 类                          | 说明                                                                 |
|----------------|--------------------------------------|----------------------------------------------------------------------|
| 画布           | `vispy.scene.SceneCanvas`            | 2D/3D 通用画布，需设置 `size`/`keys='interactive'` 开启交互          |
| 2D 视图        | `vispy.scene.ViewBox`（默认 2D）     | 承载 2D 相机和绘图元素，可通过 `add_view()` 创建                     |
| 2D 相机        | `vispy.scene.cameras.PanZoomCamera`  | 2D 核心相机：支持平移（Pan）、缩放（Zoom），无旋转，适配所有 2D 场景 |
|                | `vispy.scene.cameras.ArcballCamera`（2D 兼容） | 可用于 2D 但冗余，优先用 PanZoomCamera                              |

### 2. 2D 绘图核心 Visual（官方支持的 2D 元素）
所有 2D Visual 均在 `vispy.scene.visuals` 下，且**仅依赖 x/y 坐标**（z 轴为 0）：
| Visual 类               | 适用场景                          | 关键 API 参数                          |
|-------------------------|-----------------------------------|----------------------------------------|
| `Line`                  | 2D 折线/曲线（如正弦曲线、折线图） | `pos`（x/y 坐标数组）、`color`、`width` |
| `Rectangle`             | 2D 矩形/方框（如坐标轴、选区框）  | `pos`（左上角）、`size`、`color`、`border_color` |
| `Ellipse`               | 2D 椭圆/圆形（如散点、标记）      | `center`、`radius`、`color`            |
| `Text`                  | 2D 文本标注（如坐标轴标签、图例） | `pos`、`text`、`font_size`、`color`     |
| `Markers`               | 2D 散点图（如数据点、标记点）     | `pos`（x/y 坐标）、`size`、`symbol`（形状：circle/square 等） |
| `Image`                 | 2D 图像显示（如灰度图、RGB 图）   | `data`（图像数组）、`interpolation`（插值方式） |
| `Histogram`             | 2D 直方图（统计分布）             | `data`、`bins`、`color`                |
| `Polygon`               | 2D 多边形（如不规则选区、填充区域） | `pos`（顶点坐标）、`color`、`border_color` |
| `Axis`                  | 2D 坐标轴（带刻度、标签）         | `orientation`（x/y 轴）、`tick_label`   |
| `Grid`                  | 2D 网格线（如坐标系背景）         | `color`、`scale`（网格间距）            |

### 3. 官方定义的 2D 典型场景（API 示例对应）
1. **基础 2D 数据可视化**：Line + Markers + Axis（如折线图、散点图）；
2. **图像查看器**：Image + PanZoomCamera（如医学影像、图片缩放平移）；
3. **2D 标注/绘图工具**：Rectangle + Ellipse + Text（如目标框选、标注）；
4. **统计图表**：Histogram + Grid（如数据分布可视化）；
5. **2D 几何图形绘制**：Polygon + Line（如不规则形状、流程图）。

### 2D 场景最小示例（官方 API 标准用法）
```python
import numpy as np
from vispy.scene import SceneCanvas, visuals

# 1. 创建 2D 场景画布
canvas = SceneCanvas(keys='interactive', size=(800, 600), title="2D 场景示例")
view = canvas.central_widget.add_view()
view.camera = 'panzoom'  # 2D 核心相机

# 2. 添加 2D 绘图元素（折线+散点）
x = np.linspace(0, 10, 100)
y = np.sin(x)
line = visuals.Line(pos=np.column_stack([x, y]), color='red', width=2, parent=view.scene)
markers = visuals.Markers(pos=np.column_stack([x, y]), symbol='o', size=5, color='blue', parent=view.scene)

# 3. 显示画布
canvas.show()
if __name__ == '__main__':
    import sys
    if sys.flags.interactive != 1:
        canvas.app.run()
```

## 二、Vispy 3D 绘图场景（官方 API 核心内容）
### 1. 3D 场景核心组件（API 路径）
| 组件类型       | 官方 API 类                          | 说明                                                                 |
|----------------|--------------------------------------|----------------------------------------------------------------------|
| 画布           | `vispy.scene.SceneCanvas`            | 与 2D 通用，无需额外配置                                             |
| 3D 视图        | `vispy.scene.ViewBox`                | 仅需修改相机类型即可切换为 3D 视图                                   |
| 3D 相机        | `vispy.scene.cameras.ArcballCamera`  | 3D 核心相机：支持旋转、平移、缩放（鼠标拖拽旋转，滚轮缩放）           |
|                | `vispy.scene.cameras.TurntableCamera` | 3D 常用相机：固定一个轴旋转（如绕 z 轴），适合展示 3D 模型            |
|                | `vispy.scene.cameras.FlyCamera`      | 第一人称视角相机：适合沉浸式 3D 场景（如飞行模拟）                   |
|                | `vispy.scene.cameras.TrackballCamera`| 类似 Arcball，支持更灵活的视角调整                                   |

### 2. 3D 绘图核心 Visual（官方支持的 3D 元素）
所有 3D Visual 均在 `vispy.scene.visuals` 下，**依赖 x/y/z 三维坐标**：
| Visual 类               | 适用场景                          | 关键 API 参数                          |
|-------------------------|-----------------------------------|----------------------------------------|
| `Line`                  | 3D 折线/曲线（如 3D 轨迹、管线）  | `pos`（x/y/z 坐标数组）、`color`、`width` |
| `Mesh`                  | 3D 网格模型（如 STL 模型、曲面）  | `vertices`（顶点）、`faces`（面）、`color` |
| `Volume`                | 3D 体数据可视化（如医学体素、点云） | `data`（3D 数组）、`method`（渲染方式：mip/iso 等） |
| `Markers`               | 3D 散点图（如 3D 数据点、点云）   | `pos`（x/y/z 坐标）、`size`、`symbol`   |
| `SurfacePlot`           | 3D 曲面图（如函数曲面 z=f(x,y)）   | `x`/`y`/`z` 数组、`color`、`shading`    |
| `Cube`                  | 3D 立方体（如坐标系轴、边界框）   | `center`、`size`、`color`               |
| `Axes`                  | 3D 坐标轴（带刻度、标签）         | `x_label`/`y_label`/`z_label`、`font_size` |
| `GridLines`             | 3D 网格线（如 3D 坐标系背景）     | `scale`、`color`、`dimensions`（3D）     |
| `Text`                  | 3D 文本标注（如 3D 模型标签）     | `pos`（x/y/z）、`text`、`rotation`      |

### 3. 官方定义的 3D 典型场景（API 示例对应）
1. **3D 网格模型展示**：Mesh + ArcballCamera（如 3D 建模、CAD 模型预览）；
2. **3D 体数据可视化**：Volume + TurntableCamera（如 CT 影像、科学计算体数据）；
3. **3D 曲面/函数可视化**：SurfacePlot + GridLines（如数学函数 z=sin(x)+cos(y)）；
4. **3D 点云/轨迹可视化**：Markers + Line（如 GPS 轨迹、点云数据）；
5. **沉浸式 3D 场景**：FlyCamera + Cube + Axes（如虚拟仿真、游戏场景）；
6. **3D 坐标系/标注**：Axes + Text（如 3D 可视化的辅助标注）。

### 3D 场景最小示例（官方 API 标准用法）
```python
import numpy as np
from vispy.scene import SceneCanvas, visuals

# 1. 创建 3D 场景画布
canvas = SceneCanvas(keys='interactive', size=(800, 600), title="3D 场景示例")
view = canvas.central_widget.add_view()
view.camera = 'turntable'  # 3D 常用相机
view.camera.fov = 45  # 视角
view.camera.distance = 10  # 相机距离

# 2. 添加 3D 绘图元素（3D 曲面）
x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)
x, y = np.meshgrid(x, y)
z = np.sin(np.sqrt(x**2 + y**2))
surface = visuals.SurfacePlot(x=x, y=y, z=z, color=(0.5, 0.5, 1, 1), parent=view.scene)

# 3. 添加 3D 坐标轴
axes = visuals.Axes(parent=view.scene, label_color='white', axis_color='white', tick_color='white')

# 4. 显示画布
canvas.show()
if __name__ == '__main__':
    import sys
    if sys.flags.interactive != 1:
        canvas.app.run()
```

## 三、2D/3D 场景核心差异（官方 API 总结）
| 维度 | 核心相机                | 绘图元素关键特征       | 交互方式                | 典型 Visual                  |
|------|-------------------------|------------------------|-------------------------|------------------------------|
| 2D   | PanZoomCamera           | 仅 x/y 坐标，z=0       | 平移、缩放（无旋转）    | Line、Markers、Image、Axis   |
| 3D   | Arcball/TurntableCamera | x/y/z 三维坐标         | 旋转、平移、缩放        | Mesh、Volume、SurfacePlot、Axes |

## 四、官方扩展场景（进阶用法）
1. **混合 2D/3D 场景**：在同一个 SceneCanvas 中创建多个 ViewBox，分别设置 2D/3D 相机（如左侧 2D 控制面板，右侧 3D 视图）；
2. **交互式标注场景**：结合 Visual 的 `events`（如 `mouse_press`/`mouse_move`），实现 2D/3D 绘图的实时编辑（官方示例：`vispy/examples/scene/interactive_line.py`）；
3. **高性能批量绘图场景**：使用 `vispy.gloo` 底层 API（非 scene 层）实现大规模 2D/3D 数据绘制（如百万级点云）。

## 总结
### 关键点回顾
1. **2D 场景核心**：PanZoomCamera + 仅 x/y 坐标的 Visual（Line/Markers/Image 等），适配图表、图像、几何绘制；
2. **3D 场景核心**：Arcball/TurntableCamera + x/y/z 三维坐标的 Visual（Mesh/Volume/SurfacePlot 等），适配模型、体数据、曲面可视化；
3. 通用基础：所有场景均基于 `SceneCanvas` + `ViewBox`，仅需切换相机和 Visual 类型即可实现 2D/3D 切换；
4. 官方示例：可通过 `vispy.examples` 查看完整场景代码（如 `scene/` 目录下的 2D/3D 示例）。

Vispy 官方 API 对 2D/3D 场景的划分核心在于「坐标维度」和「相机类型」，绘图元素大部分可复用（如 Line/Markers 支持 2D/3D），只需调整坐标维度即可适配不同场景。
