## 问题重新分析

### 问题 1：test_navigation.py 最大化后云母特效失效

#### 问题根源
经过仔细排查，发现真正的原因是：
- `test_vispy_widget.py` 使用的是 **`resizeEvent`** 而不是 `changeEvent`
- `resizeEvent` 会在窗口大小改变时触发（包括最大化）
- 关键检查条件：`hasattr(self, '_isMicaEnabled') and self._isMicaEnabled`

#### 错误的理解
之前认为应该使用 `changeEvent` 监听 `WindowStateChange`，但实际上：
- `changeEvent` 监听的是状态变化事件
- **`resizeEvent` 是更直接的解决方案**，因为最大化本质上就是窗口大小的改变

#### 正确的解决方案

```python
def resizeEvent(self, e):
    """重写 resizeEvent 以确保云母/亚克力特效在最大化后仍然有效"""
    from PySide6.QtCore import QTimer
    super().resizeEvent(e)
    # 在 Windows 11 上重新应用特效（解决最大化后失效的问题）
    if hasattr(self, '_isMicaEnabled') and self._isMicaEnabled:
        # 延迟刷新云母特效，确保窗口大小调整完成
        QTimer.singleShot(10, lambda: self.setMicaEffectEnabled(True))
    elif hasattr(self, '_isAcrylicEnabled') and self._isAcrylicEnabled:
        QTimer.singleShot(10, lambda: self.setAcrylicEffectEnabled(True))
```

#### 为什么 test_vispy_widget.py 正常工作？
因为它已经实现了 `resizeEvent`，而 vispy 的使用与此**无关**。

### 问题 2：2D 场景中增加 Shift+左键自由旋转

#### 需求理解
- 不是指 Z 轴的"俯视旋转"（那确实不支持）
- 而是指 **XY 平面的自由旋转**（绕 Z 轴旋转视图）
- 通过 Shift+左键拖动实现

#### 实现方案

##### 1. 在 VispyCanvas2D 中添加旋转状态和鼠标事件处理

class VispyCanvas2D(VispyCanvasBase):
    def __init__(self):
        super().__init__(camera_mode='panzoom')
        
        # 旋转状态（绕 Z 轴，单位：度）
        self._rotation_angle = 0.0
        self._rotating = False
        self._last_mouse_pos = None
        
        if not VISPY_AVAILABLE:
            return
        
        # 连接鼠标事件
        if self.canvas:
            self.canvas.events.mouse_press.connect(self.on_mouse_press)

            self.canvas.events.mouse_move.connect(self.on_mouse_move)
        
        # 初始化 2D 网格
        self._init_grid()

##### 2. 实现旋转方法

```python
def set_rotation(self, angle: float):
    """设置旋转角度（绕 Z 轴）"""
    if not VISPY_AVAILABLE or not self.view:
        return
    
    self._rotation_angle = angle % 360
    self._apply_rotation()

def _apply_rotation(self):
    """应用旋转变换"""
    if not VISPY_AVAILABLE or not self.view:
        return
    
    try:
        from vispy.util.transforms import rotate
        # 绕 Z 轴旋转
        angle_rad = np.radians(self._rotation_angle)
        
        # 获取相机的变换矩阵并应用旋转
        if hasattr(self.view.camera, 'transform'):
            rotation_matrix = rotate(self._rotation_angle, (0, 0, 1))
            self.view.camera.transform.reset()
            self.view.camera.transform.rotate(self._rotation_angle, (0, 0, 1))
        
        if self.canvas:
            self.canvas.update()
    except Exception as e:
        print(f"Error applying rotation: {e}")
```

##### 3. 实现鼠标事件处理

```python
def on_mouse_press(self, event):
    """鼠标按下事件"""
    if not VISPY_AVAILABLE:
        return
    
    # Shift + 左键：开始旋转
    if event.button == 1 and 'Shift' in event.modifiers:
        self._rotating = True
        self._last_mouse_pos = event.pos
        event.handled = True

def on_mouse_move(self, event):
    """鼠标移动事件"""
    if not VISPY_AVAILABLE:
        return
    
    # Shift + 左键拖动：旋转
    if self._rotating and self._last_mouse_pos is not None:
        # 计算鼠标移动距离
        dx = event.pos[0] - self._last_mouse_pos[0]
        dy = event.pos[1] - self._last_mouse_pos[1]
        
        # 根据横向移动距离计算旋转角度
        # 移动 100 像素 = 旋转 90 度
        delta_angle = dx * 0.9
        
        self.rotate_by(delta_angle)
        
        self._last_mouse_pos = event.pos
        event.handled = True

def on_mouse_release(self, event):
    """鼠标释放事件"""
    if not VISPY_AVAILABLE:
        return
    
    if event.button == 1 and self._rotating:
        self._rotating = False
        self._last_mouse_pos = None
        event.handled = True
```

##### 4. 在 VispyWidget2D 中暴露接口

```python
def set_rotation(self, angle: float):
    """设置旋转角度（绕 Z 轴）"""
    if self.canvas:
        self.canvas.set_rotation(angle)

def rotate_by(self, delta_angle: float):
    """增量旋转"""
    if self.canvas:
        self.canvas.rotate_by(delta_angle)

def reset_rotation(self):
    """重置旋转"""
    if self.canvas:
        self.canvas.reset_rotation()

def get_rotation(self) -> float:
    """获取当前旋转角度"""
    if self.canvas:
        return self.canvas.get_rotation()
    return 0.0
```

## 关键技术点

### 1. 为什么使用 resizeEvent 而不是 changeEvent？
- **resizeEvent** 在窗口大小改变时触发（包括最大化）
- **changeEvent** 在窗口状态改变时触发（更通用，但需要额外判断）
- 对于云母特效失效问题，**resizeEvent 更直接有效**

### 2. 为什么需要延迟刷新（QTimer.singleShot）？
- Windows 在窗口大小调整时会清除视觉特效
- 需要等待窗口大小调整完全完成后再重新应用特效
- 10ms 的延迟足够避免竞态条件

### 3. 2D 旋转的实现原理
- PanZoomCamera 本身不支持旋转
- 通过 `camera.transform.rotate()` 应用旋转变换
- 旋转是绕 Z 轴（垂直于屏幕）进行的

### 4. 鼠标事件处理
- 通过 `canvas.events.mouse_press/mouse_move/mouse_release` 连接事件
- 检查 `event.modifiers` 判断是否按下 Shift 键
- 设置 `event.handled = True` 阻止事件传递给默认相机控制器
