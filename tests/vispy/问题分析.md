# Vispy 测试程序问题分析与解答

## 问题 1：为什么 FluentWindow 在点击最大化后云母效果会失效？

### 问题原因分析

通过对比 `test_vispy_widget.py` 和 `test_navigation.py` 的代码，发现两个关键差异：

#### 1. **Windows 系统行为**
- Windows 在窗口状态改变（如最大化、恢复）时会**清除部分视觉特效**
- 云母特效（Mica Effect）依赖于 Windows Composition API
- 窗口最大化时，系统会重新绘制窗口，导致云母特效被清除

#### 2. **FluentWindow 的实现问题**
在 `qfluentwidgets/window/fluent_window.py` 中：

```python
def resizeEvent(self, e):
    # 只处理导航栏展开/折叠逻辑
    if self.width() >= 1200 and ...:
        self.navigationInterface.expand()
    super().resizeEvent(e)
    # 没有重新应用云母特效的代码
```

**缺少的关键步骤**：窗口大小改变后没有重新应用云母特效。

#### 3. **test_navigation.py 为什么也会失效**
```python
class Window(FluentWindow):
    def __init__(self):
        super().__init__(showReturnButton=True)
        # 没有调用 setMicaEffectEnabled(True)
        # 默认云母特效未启用
```

`test_navigation.py` 根本**没有启用云母特效**，所以看起来"没有问题"。

---

### 解决方案

#### 方案 1：在 VispyTestWindow 中重写 resizeEvent（已实现）

```python
class VispyTestWindow(FluentWindow):
    def resizeEvent(self, e):
        """重写 resizeEvent 以确保云母特效在最大化后仍然有效"""
        super().resizeEvent(e)
        # 在 Windows 11 上重新应用云母特效
        if hasattr(self, '_isMicaEnabled') and self._isMicaEnabled:
            # 延迟刷新云母特效，确保窗口大小调整完成
            from PySide6.QtCore import QTimer
            QTimer.singleShot(10, lambda: self.setMicaEffectEnabled(True))
```

**原理**：
- 窗口大小改变后，延迟 10ms 重新应用云母特效
- 延迟是为了确保窗口布局已完成，避免竞态条件
- `setMicaEffectEnabled(True)` 会调用 Windows API 重新设置云母效果

#### 方案 2：修改 FluentWidget 基类（根本解决）

在 `qfluentwidgets/window/fluent_window.py` 的 `FluentWidget` 类中添加：

```python
def resizeEvent(self, e):
    super().resizeEvent(e)
    # 窗口大小改变后重新应用特效
    if self.isMicaEffectEnabled():
        QTimer.singleShot(10, lambda: self.setMicaEffectEnabled(True))
    elif self.isAcrylicEffectEnabled():
        QTimer.singleShot(10, lambda: self.setAcrylicEffectEnabled(True))
```

## 问题 2：测试代码中可见性控制组的作用是什么？

### 功能说明

**可见性控制组（Visibility Control Group）** 是测试程序中的一个重要功能模块，用于动态控制场景中各个图形元素的显示/隐藏。

### 实现细节

```python
# 1. 在控制面板中创建可见性控制组
vis_group = QGroupBox("可见性")
self.vis_layout = QVBoxLayout(vis_group)

# 2. 为每个图形元素添加复选框
self._add_visibility_checkbox('sine', '正弦曲线', True)
self._add_visibility_checkbox('cosine', '余弦曲线', True)
self._add_visibility_checkbox('markers', '散点', True)

# 3. 复选框状态改变时调用
def _on_visibility_changed(self, visual_id: str, state: int):
    if self.has_vispy and visual_id in self.visual_ids:
        is_visible = (state == 2)  # Qt.Checked = 2
        self.vispyWidget.set_visible(self.visual_ids[visual_id], is_visible)
```

### 使用场景

1. **调试与开发**
   - 快速切换元素可见性，排查渲染问题
   - 对比不同元素的显示效果

2. **用户交互**
   - 允许用户自定义显示内容
   - 类似图层管理器（如 Photoshop 的图层面板）

3. **性能优化**
   - 隐藏不需要的元素，减少渲染负担
   - 在大数据量场景中特别有用

### 底层实现

调用 `VispyWidget.set_visible(visual_id, visible)` 会：

1. 在 `vispy_canvas.py` 中找到对应的 `VisualEntry`
2. 调用 `entry.set_visible(visible)`
3. 底层调用 Vispy 的 `visual.visible = visible`
4. Vispy 自动跳过不可见元素的渲染

### 优势

- ✅ **实时响应**：复选框改变立即生效，无需刷新
- ✅ **内存高效**：隐藏的元素不渲染，但数据保留在内存中
- ✅ **可扩展**：可以轻松添加更多控制选项（透明度、颜色等）

## 问题 3：在测试代码中 2D 场景，Vispy 旋转画布如何操作？

### 重要说明：2D 场景不支持旋转

**2D 场景使用 PanZoomCamera（平移-缩放相机），设计上不支持旋转功能。**

### 原因分析

#### 1. **相机类型决定**

在 `vispy_canvas.py` 中：

```python
class VispyCanvas2D(VispyCanvasBase):
    def __init__(self):
        super().__init__(camera_mode='panzoom')  # 使用 PanZoomCamera
```

**PanZoomCamera 特性**：
- ✅ 支持：平移（Pan）、缩放（Zoom）
- ❌ 不支持：旋转（Rotation）
- 适用场景：2D 数据可视化、图像查看器、图表绘制

#### 2. **设计理念**

2D 场景设计为**俯视图（Top-Down View）**：
- 所有元素的 z 坐标为 0
- 相机垂直向下看（固定角度）
- 旋转会导致视角混乱（看到侧面会是一条线）

#### 3. **如果强行旋转会发生什么？**

假设我们修改代码使用 `TurntableCamera`：

```python
class VispyCanvas2D(VispyCanvasBase):
    def __init__(self):
        super().__init__(camera_mode='turntable')  # 错误示例
```

**结果**：
- 旋转后会看到 2D 图形的"侧面"
- 由于所有元素 z=0，旋转后看到的是一条线
- 用户体验极差，失去 2D 可视化的意义

---

### 2D 场景支持的操作

| 操作 | 方法 | 说明 |
|------|------|------|
| **平移** | 鼠标左键拖动 | 移动视图中心 |
| **缩放** | 鼠标滚轮 | 放大/缩小视图 |
| **重置视图** | 点击"重置视图"按钮 | 调用 `auto_range()` 自动适应所有元素 |

### 3D 场景支持的操作（对比）

| 操作 | 方法 | 说明 |
|------|------|------|
| **旋转** | 鼠标左键拖动 | 绕固定轴旋转（TurntableCamera） |
| **平移** | 鼠标中键拖动 | 移动视图中心 |
| **缩放** | 鼠标滚轮 / 右键拖动 | 放大/缩小视图 |
| **视角切换** | 点击视角按钮 | 快速切换到预设视角（顶视图、前视图等） |

---

### 如果确实需要 2D 旋转怎么办？

#### 方案 1：使用 3D 场景模拟 2D（推荐）

```python
# 在 3D 场景中绘制 2D 图形，然后固定视角
widget3d = VispyWidget3D()

# 添加 2D 图形（z=0）
x = np.linspace(0, 10, 100)
y = np.sin(x)
z = np.zeros_like(x)
pos = np.column_stack([x, y, z])
widget3d.add_line3d(pos, color='red', width=2)

# 设置为顶视图（模拟 2D）
widget3d.set_view('top')

# 用户可以旋转查看不同角度
```

#### 方案 2：修改相机类型（不推荐）

```python
# 在 vispy_canvas.py 中修改
class VispyCanvas2D(VispyCanvasBase):
    def __init__(self):
        super().__init__(camera_mode='turntable')  # 改用支持旋转的相机
```

**缺点**：
- 破坏了 2D 场景的设计理念
- 用户体验差（旋转后看到的是线）
- 不符合 2D 可视化的最佳实践

## 总结

### 问题 1 答案
FluentWindow 最大化后云母特效失效是因为：
1. Windows 系统在窗口状态改变时清除视觉特效
2. FluentWindow 的 resizeEvent 没有重新应用云母特效
3. 解决方法：在 resizeEvent 中延迟调用 `setMicaEffectEnabled(True)`

### 问题 2 答案
可见性控制组的作用：
1. 动态控制场景中各个图形元素的显示/隐藏
2. 类似图层管理器，提供精细的可见性控制
3. 底层调用 `VispyWidget.set_visible(visual_id, visible)`
4. 用于调试、用户交互和性能优化

### 问题 3 答案
2D 场景不支持旋转操作，原因：
1. 使用 PanZoomCamera，设计上不支持旋转
2. 2D 场景是俯视图，旋转会导致视角混乱
3. 支持的操作：平移（左键拖动）、缩放（滚轮）
4. 如需旋转功能，请使用 3D 场景
